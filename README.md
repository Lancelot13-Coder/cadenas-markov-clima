\# Simulador Climático mediante Cadenas de Markov



Proyecto académico de desarrollo de una aplicación web para

modelar y simular estados climáticos utilizando cadenas

de Markov.



\## Tecnologías



\- Python

\- Django

\- HTML

\- CSS

\- JavaScript

\- Git y GitHub

\- OpenSpec (SDD)



\## Estado del proyecto



En fase de planificación e ingeniería.
